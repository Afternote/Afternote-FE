# predictive back 수동 확인 절차

Nav2 백스택 회귀 기준(#1601)의 다섯 축 중 **predictive back** 만 자동화가 반쪽이다.
백스택이 어떻게 바뀌는지는 JVM 테스트가 전부 고정하지만,
**손가락을 떼기 전에 화면이 어떻게 보이는지**는 원격 조작으로 재현할 수 없다.
이 문서는 그 남은 반쪽의 절차다.

## 자동으로 이미 고정한 것 — 다시 손으로 보지 않는다

`app/src/test/java/com/afternote/afternote_fe/navigation/PredictiveBackNavigationTest.kt`
(`:app:testDebugUnitTest`, 5건). `OnBackPressedDispatcher.dispatchOnBackStarted` /
`dispatchOnBackProgressed` / `dispatchOnBackCancelled` 를 그대로 흘려 넣어 검사한다.

- 진행 중(손가락을 떼기 전)에는 백스택이 아직 그대로다
- 취소하면 떠나려던 화면에 남는다
- 끝까지 진행하면 **한 칸만** pop 된다
- 취소한 직후 다시 시작해도 정상적으로 pop 된다
- 탭 그래프의 시작 화면에서 진행하면 그래프 엔트리까지 함께 빠지고 홈 탭이 남는다(앱을 벗어나지 않는다)

## 수동으로만 볼 수 있는 것

| 항목 | 왜 자동이 안 되나 |
| --- | --- |
| 진행 중 앞 화면의 축소·모서리 곡률·가장자리 여백 | 픽셀 판정이고, Robolectric 은 프레임을 돌리지 않는다 |
| 진행률에 따라 미리보기가 따라오는지(스크럽 감각) | 실제 터치 홀드가 필요하다 — `adb`·계측 모두 «진행 중» 상태를 유지하지 못한다 |
| 취소 시 앞 화면이 제자리로 되돌아가는 애니메이션 | 위와 같다. JVM 테스트에서는 미리보기가 끝내 사라지지 않는데, 이는 프레임이 없기 때문이지 기기 동작이 아니다 |
| 시스템 back-to-home 전환(앱 밖으로) | 앱 밖 영역이라 앱 테스트의 관측 범위 밖이다 |

## 절차

기기 조건 — **API 35 이상**. 앱이 `enableOnBackInvokedCallback` 을 명시하지 않지만
`targetSdk 36` 이라 시스템 기본값으로 predictive back 이 켜진다.
기기 설정에서 «뒤로 탐색 애니메이션» 이 켜져 있어야 한다(개발자 옵션이 아니라 기본 켜짐).
제스처 내비게이션 모드여야 한다 — 3버튼 모드에서는 predictive back 이 동작하지 않는다.

각 항목은 **왼쪽 가장자리에서 오른쪽으로 천천히 끌되 손가락을 떼지 않은 채** 관찰한다.

### 1. 탭 안 깊은 화면 — 진행·취소·완료

1. 로그인 → 타임레터 탭 → 임시저장 목록으로 들어간다.
2. 화면 폭의 30% 쯤까지 끌고 **멈춘다**.
   - [ ] 임시저장 화면이 축소되고 모서리가 둥글어지며, 뒤로 타임레터 홈이 비친다.
3. 손가락을 **왼쪽으로 되돌려 놓고 뗀다**(취소).
   - [ ] 임시저장 화면이 원래 크기로 되돌아가고 그 화면에 남는다.
4. 다시 끌어서 화면 밖까지 완료한다.
   - [ ] 타임레터 홈으로 간다. 홈 탭으로 튀지 않는다.

### 2. 탭 시작 화면 — 앱을 벗어나지 않는다

1. 타임레터 홈(탭 시작 화면)에서 같은 제스처를 완료한다.
   - [ ] 홈 탭으로 간다. 앱이 종료되지 않는다.
2. 홈 탭에서 한 번 더 완료한다.
   - [ ] 이때는 앱을 벗어난다(런처로 나간다).

### 3. 인증 관문 — 뒤로 가서 관문을 건너뛰지 못한다

1. 애프터노트 탭 진입 → 지문 인증 통과 → 애프터노트 홈.
2. 제스처를 완료한다.
   - [ ] 지문 관문이 아니라 홈 탭으로 간다.
3. 다시 애프터노트 탭을 누른다.
   - [ ] 지문 관문이 다시 선다(저장된 스택으로 복원되지 않는다).

### 4. 되돌리기 가드가 걸린 화면 — 제스처가 다이얼로그에 막힌다

애프터노트 에디터는 미저장 변경이 있으면 `BackHandler` 로 뒤로가기를 가로챈다.

1. 애프터노트 에디터에 들어가 아무 입력이나 한 글자 넣는다.
2. 제스처를 시작한다.
   - [ ] **앞 화면 미리보기가 뜨지 않는다**(가로챈 콜백은 진행 이벤트를 소비하지 않는다).
   - [ ] 완료하면 이탈 확인 다이얼로그가 뜬다. 화면은 그대로다.
