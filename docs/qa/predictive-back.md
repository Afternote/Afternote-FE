# predictive back 수동 확인 절차

Nav2 백스택 회귀 기준(#1601)의 다섯 축 중 **predictive back** 만 자동화가 반쪽이다.
백스택이 어떻게 바뀌는지는 JVM 테스트가 전부 고정하지만,
**손가락을 떼기 전에 화면이 어떻게 보이는지**는 원격 조작으로 재현할 수 없다.
이 문서는 그 남은 반쪽의 절차다.

## 자동으로 이미 고정한 것 — 다시 손으로 보지 않는다

`app/src/test/java/com/afternote/afternote_fe/navigation/PredictiveBackNavigationTest.kt`
(`:app:testDebugUnitTest`, 5건). `OnBackPressedDispatcher.dispatchOnBackStarted` /
`dispatchOnBackProgressed` / `dispatchOnBackCancelled` 를 그대로 흘려 넣어 검사한다.

- 진행 중(손가락을 떼기 전)에는 백스택이 아직 그대로다
- 취소하면 떠나려던 화면에 남는다
- 끝까지 진행하면 **한 칸만** pop 된다
- 취소한 직후 다시 시작해도 정상적으로 pop 된다
- 탭 그래프의 시작 화면에서 진행하면 그래프 엔트리까지 함께 빠지고 홈 탭이 남는다(앱을 벗어나지 않는다)

## 수동으로만 볼 수 있는 것

| 항목 | 왜 자동이 안 되나 |
| --- | --- |
| 진행 중 앞 화면의 축소 비율·가장자리 여백 | 픽셀 판정이고, Robolectric 은 프레임을 돌리지 않는다 |
| 진행률에 따라 미리보기가 따라오는지(스크럽 감각) | 실제 터치 홀드가 필요하다 — `adb`·계측 모두 «진행 중» 상태를 유지하지 못한다 |
| 취소 시 앞 화면이 제자리로 되돌아가는 애니메이션 | 위와 같다. JVM 테스트에서는 미리보기가 끝내 사라지지 않는데, 이는 프레임이 없기 때문이지 기기 동작이 아니다 |
| 시스템 back-to-home 전환(앱 밖으로) | 앱 밖 영역이라 앱 테스트의 관측 범위 밖이다 |

## 모서리 라운딩은 기대에 넣지 않는다

pop 전환이 주는 것은 축소(`scaleOut(targetScale = 0.7f)`)까지다. Compose 의 `ExitTransition` 은
fade, scale, slide, shrink 만 담을 수 있어 clip 이나 shape 를 표현하지 못하고,
Nav3 로컬 스택이 쓰는 라이브러리 기본값(`defaultPredictivePopTransitionSpec()`)도 축소 하나뿐이다.

이 문서가 처음 적어 둔 "모서리가 둥글어지며" 는 시스템 기본 동작을 보고 쓴 기대였지,
앱이 그리는 화면의 기준이 아니었다. #1869 에서 축소를 붙이며 기준 쪽을 고쳤다.

## 절차

기기 조건: Android 16(API 36) 이상. 앱이 `enableOnBackInvokedCallback` 을 명시하지 않지만
`targetSdk 36` 이라 Android 16 에서는 시스템 기본값으로 predictive back 이 켜진다.
API 35 에서는 켜지지 않는다. 2026-09-23 API 35 에뮬레이터(제스처 내비게이션)에서 가장자리를 끌면
시스템 뒤로 화살표만 뜨고 앱 화면은 줄지 않았다(#2145). API 35 에뮬레이터로 봐야 하면 로컬 확인용
빌드에만 매니페스트 `<application>` 에 `android:enableOnBackInvokedCallback="true"` 를 넣는다. 커밋하지 않는다.
기기 설정에서 «뒤로 탐색 애니메이션» 이 켜져 있어야 한다(개발자 옵션이 아니라 기본 켜짐).
제스처 내비게이션 모드여야 한다 — 3버튼 모드에서는 predictive back 이 동작하지 않는다.

각 항목은 **왼쪽 가장자리에서 오른쪽으로 천천히 끌되 손가락을 떼지 않은 채** 관찰한다.

### 1. 탭 안 깊은 화면 — 진행·취소·완료

1. 로그인 → 타임레터 탭 → 임시저장 목록으로 들어간다.
2. 화면 폭의 30% 쯤까지 끌고 **멈춘다**.
   - [ ] 임시저장 화면이 줄어들어 뒤로 물러나고, 그 뒤로 타임레터 홈이 비친다.
         두 화면이 같은 크기로 겹쳐 글자가 서로 비치면 실패다(#1869).
3. 손가락을 **왼쪽으로 되돌려 놓고 뗀다**(취소).
   - [ ] 임시저장 화면이 원래 크기로 되돌아가고 그 화면에 남는다.
4. 다시 끌어서 화면 밖까지 완료한다.
   - [ ] 타임레터 홈으로 간다. 홈 탭으로 튀지 않는다.

### 2. 탭 시작 화면 — 앱을 벗어나지 않는다

1. 타임레터 홈(탭 시작 화면)에서 같은 제스처를 완료한다.
   - [ ] 홈 탭으로 간다. 앱이 종료되지 않는다.
2. 홈 탭에서 한 번 더 완료한다.
   - [ ] 이때는 앱을 벗어난다(런처로 나간다).

### 3. 인증 관문 — 뒤로 가서 관문을 건너뛰지 못한다

1. 애프터노트 탭 진입 → 지문 인증 통과 → 애프터노트 홈.
2. 제스처를 완료한다.
   - [ ] 지문 관문이 아니라 홈 탭으로 간다.
3. 다시 애프터노트 탭을 누른다.
   - [ ] 지문 관문이 다시 선다(저장된 스택으로 복원되지 않는다).

### 4. 되돌리기 가드가 걸린 화면 — 제스처가 다이얼로그에 막힌다

애프터노트 에디터는 미저장 변경이 있으면 `BackHandler` 로 뒤로가기를 가로챈다.

1. 애프터노트 에디터에 들어가 아무 입력이나 한 글자 넣는다.
2. 제스처를 시작한다.
   - [ ] **앞 화면 미리보기가 뜨지 않는다**(가로챈 콜백은 진행 이벤트를 소비하지 않는다).
   - [ ] 완료하면 이탈 확인 다이얼로그가 뜬다. 화면은 그대로다.

### 5. 앞 화면 바탕: 뒤 화면 글자가 비치지 않는다 (#2145)

화면 대부분이 투명한 `Scaffold` 라, 목적지가 바탕을 깔지 않으면 줄어든 앞 화면 사이로 뒤 화면이 보인다.
Nav3 로컬 스택은 표준 entry 데코레이터가 까므로 스택 안쪽과 host 바닥을 따로 본다.

1. 설정 > 알림 설정으로 들어가 30% 쯤 끌고 멈춘다(설정 로컬 스택 안, #1695).
   - [ ] 줄어든 알림 설정 화면 안에 설정 목록의 글자·프로필이 겹쳐 보이지 않는다.
2. 노트 탭 > 애프터노트 한 건의 상세로 들어가 같은 제스처로 멈춘다(애프터노트 로컬 스택 안).
   - [ ] 줄어든 상세 화면 안에 애프터노트 목록의 카드·탭 글자가 겹쳐 보이지 않는다.
3. 애프터노트 홈(로컬 스택 바닥)에서 같은 제스처로 멈춘다(루트로 빠지는 Nav3 host).
   - [ ] 줄어든 애프터노트 홈 안에 홈 탭의 로고·문구가 겹쳐 보이지 않는다.

Nav2 목적지는 등록부가 직접 감싸야 하는데, 설정이 Nav3 로 옮겨 간 뒤로 감싼 Nav2 목적지가 남아 있지 않다.
타임레터·마음의 기록은 아직 이 항목을 통과하지 못한다. 두 그래프는 Nav2 로 남아 있어
#2149(타임레터)·#2150(마음의 기록)이 감싸고, 감싼 화면으로 1 과 같은 항목을 더한다.
