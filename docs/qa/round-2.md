## 확인된 개선

1차 QA에서 지적한 애프터노트 등록 실패(서버 오류)와 오류 응답의 내부 정보 노출은 이번 회차에서 정상 동작으로 확인했다. 공지사항 빈 화면(20번)도 수정이 반영돼 빈 상태 안내가 표시된다. 패스키 목록 화면은 기기 지문을 등록해 도달에 성공했고, 항목이 자리표시자 그대로 표시되는 문제를 따로 등록했다.

## 기획 확인 필요

- 타임레터 발송 시간을 고르지 않아도 등록되고 자정으로 저장된다. 시간이 필수인지 확인 필요.
- 노트 작성에서 수신자를 새로 입력받는데, 설정에 등록해 둔 수신자를 재사용하는 게 맞는지 확인 필요.
- 수신자 등록·선택 완료 시 성공 안내 없이 이전 화면으로 돌아간다. 피드백이 필요한지 확인 필요.
- 무료 플랜 제한 팝업의 "구독 후 기록하기"는 팝업만 닫힌다. 구독 화면이 아직 없다.
